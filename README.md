# Velora

Velora is a modern e-commerce application built with a scalable and performance-focused tech stack.

## Tech Stack

### Frontend
- **Next.js**
  - Enhances performance with Server-Side Rendering (SSR)
  - Improves SEO for better visibility
  - Uses prebuilt UI components for faster and consistent development

### Backend
- **NestJS**
  - Provides a scalable and maintainable architecture
  - Follows modular design principles
  - Supports performance optimization and clean code practices

### Database
- **Supabase**
  - Uses PostgreSQL for structured data management
  - Provides a reliable and efficient relational database system
  - Simplifies backend integration with built-in features
